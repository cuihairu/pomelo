### 面二：浏览器语言自动识别切换

受规形态：**②文档站 locale 路由**（`docs/.vitepress/config.mts:8` `locales: { root: ..., zh: ... }`，`/`=en、`/zh/`=zh），另有 README.md/README.zh.md 成对文件。

**本仓已具备浏览器语言自动识别**，`docs/index.md:30-45` 与 `docs/zh/index.md:29-50` 各一段 `<script setup>`：首次访问时若 `navigator.languages` 以 `zh` 开头则 `location.replace` 到 `/zh/`；手动点过语言链接后写 `localStorage['pomelo-lang-auto-picked']`，之后以手动选择优先（19f6230 已把该脚本镜像到 zh 首页）。线上实测：`https://cuihairu.github.io/pomelo/` 200、`lang="en"`、首屏 CJK 4；`…/zh/` 200、`lang="zh-CN"`、首屏 CJK 6。

结论：**无需立 P2 todo**——本仓自动识别已落地，属受规形态 + 增强项双达。

> 探针盲区（回舰队总账）：`standards/scripts/fleet-url-contract.py` 只在 vitepress/docusaurus/mkdocs 的 **config 与 theme 目录**里找 `navigator.language`，而 pomelo 的自动识别写在 `.md` 页面源里的 `<script setup>` 中，故探针报 `auto_switch=None`。该结论对本仓不成立，全舰队同口径的「零自动切换」同样受此盲区影响，需按页源复扫后再定。
